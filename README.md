# Transformed Storage

**Transformed Storage** is a curated Vanilla+ Minecraft modpack focused on expanding storage, organization, automation, performance improvements and quality-of-life features while preserving the feel of Vanilla Minecraft.  This pack works excellently for both single-player and multiplayer.

## Major Mods

### ⚡ Energized Power
Adds a lightweight technology and automation system, including power generation, ore processing, powered machines, conveyors, and other automation tools.

### 📦 Tom's Simple Storage
Connect your inventories together into a unified storage network with a searchable terminal, making large storage systems significantly easier to manage.

### 🗄️ Storage Drawers
Provides high-capacity bulk storage using configurable drawers, compacting drawers, drawer controllers, and storage upgrades.

### 🧰 Iron Chests
Expands traditional chest storage with larger-capacity single chest tiers.

## Vanilla+ Experience

Transformed Storage is intended to expand upon Minecraft rather than completely change it. The mod selection focuses on:

- Improved storage and inventory management
- Lightweight technology and automation
- Quality-of-life improvements
- Performance and optimizations
